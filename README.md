# 高顿紫藤留学&背景提升智能咨询工作台

这是一个静态网页顾问工具，用于留学申请、背景提升、科研竞赛实习、智能定校和咨询话术生成。

## 文件结构

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：产品库、推荐规则、定校辅助逻辑

## 使用方式

打开 GitHub Pages 后，填写学生信息，点击“一键生成咨询方案”或“生成定校方案”。

工具会生成：

- 学生画像与核心诊断
- 时间风险判断
- 冲刺/匹配/保底定校思路
- 基础/进阶/高配产品组合
- 背景提升与竞赛建议
- 院校名单/白名单核查 checklist
- 探需问题
- 家长话术
- 内部顾问分析
- 查校关键词与官方查校网站链接

## 维护方式

产品数据集中在 `script.js` 顶部的 `products` 数组里。后续新增产品时，按以下字段补充：

```js
{name:'产品名称',code:'产品码',cat:'分类',country:'地区',stage:'阶段',price:'价格',tags:['标签'],desc:'产品说明'}
```

查校资源在 `resources` 对象里维护，可继续增加各国家官方查校网站。

## 注意

本工具只做顾问咨询辅助，不替代院校官网核查。申请要求、截止日期、费用、院校名单和录取标准必须以院校官网最新信息为准。
